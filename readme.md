📦 Selenium Python Automation Project – Daraz Automation Feamework

This project is a simple yet scalable Selenium automation framework built with Python and Pytest, designed using the Page Object Model (POM) approach.

It automates a real user scenario on Daraz — searching for a product — while keeping the code clean, reusable, and easy to extend.

🚀 What This Project Covers
It automates each scenario of daraz and provides end to end testing automation
Structured automation using POM
Clean separation of test logic and page actions

🧠 Why This Framework?

Instead of writing everything in one file, this project follows best practices used in real QA teams:

✔ Keeps tests readable
✔ Makes maintenance easier
✔ Encourages reusability
✔ Easy to scale for larger projects
